# The Ark Forecast 🌦️

A modern Android weather application built with Jetpack Compose and OpenWeatherMap API.

## 🚀 Features
- **Glassmorphism UI**: High-end visual design with dynamic backgrounds.
- **Custom Icon Engine**: Swaps between Material Icons and custom XML vectors for specific weather states.
- **Search History**: Persistent local storage using Room Database.
- **Real-time Data**: Displays temperature, wind speed, pressure, and sunrise/sunset times.

## 🛠️ Tech Stack
- **Language**: Kotlin
- **UI**: Jetpack Compose
- **Networking**: Retrofit & GSON
- **Database**: Room
- **Location**: Fused Location Provider
